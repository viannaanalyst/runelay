Questions

Which agents does it work with?

Any MCP client. And a single command imports the memories, skills and instructions you already have in Claude Code, Codex, Cursor, Grok, Gemini and OpenCode.

Do I need Docker or a server?

No. Download the app for Mac, Windows or Linux and it runs on your computer. Want it always on, for every machine you use? Install it on a server with Docker in one command.

Can I migrate in one click?

Yes. Run runelay migrate: it finds Claude Code, Codex, Cursor and Grok on your machine and brings everything over at once, with connections, memories, skills and instructions. Accounts your agent was already logged into arrive connected, and the ones that need a login go into a queue you clear on a single screen. Coming from Executor, it arrives as a connection that is already logged in.

Do I need to pay for anything?

No. It is a free app (or one container) with SQLite. The only accounts involved are the ones you connect.

Is it faster than a cloud service?

Calls go from your machine straight to Linear, GitHub or whoever, without passing through anyone else's infrastructure.
