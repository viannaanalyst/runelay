O que um MCP gateway faz

Sem gateway, cada agente se conecta sozinho a cada servidor MCP. Cada servidor manda a lista inteira de tools na conexão, e você faz login no Linear uma vez por agente.

O gateway fica no meio. Os agentes conectam uma vez, ele guarda as credenciais e, em vez de 125 schemas, expõe poucas tools para buscar e chamar sob demanda.

Por que hospedar você mesmo

  • Os tokens ficam com vocêTokens OAuth e chaves de API no seu servidor, criptografados com AES-256-GCM.
  • Sem preço por assentoSem limite de chamadas e sem plano para estourar. MIT e gratuito.
  • Local primeiroRoda em 127.0.0.1 como app de desktop, ou em qualquer servidor com Docker.
  • Toda chamada auditadaUm log para todos os agentes, uma chave por agente.
  • Código que você lêBun, Hono e SQLite num repositório só.
  • Começa com o seu setupImporta o que Claude Code, Codex, Cursor e Grok já têm.

O que conferir antes de escolher

  • OAuth em um clique para os apps que você usa, mais MCP remoto, MCP local e specs OpenAPI.
  • Pouco contexto na conexão, com schemas carregados só quando precisa.
  • Criptografia em repouso e proteção contra requisições a endereços privados.
  • Uma chave por agente, para uma chave vazada ficar a um clique de ser revogada.
  • Um jeito de importar o que seus agentes já têm em vez de começar do zero.

Rode o runelay em um minuto

  1. 1

    Instale o servidor

    Em qualquer máquina com Docker. Ele mostra um link de primeiro acesso para criar a conta dona.

    $curl -fsSL runelay.com/install | sh
  2. 2

    Instale a CLI e faça login

    No seu computador, depois aprove o código de login no navegador.

    $curl -fsSL runelay.com/cli | sh && runelay login
  3. 3

    Traga o que você tem e conecte

    Importa servidores MCP, memórias, skills e instruções, e registra o runelay nos seus agentes.

    $runelay migrate && runelay connect

Sem servidor? Baixe o app de desktop para Mac, Windows ou Linux. O mesmo gateway, sem Docker.

Perguntas

Preciso de servidor para ter um MCP gateway self-hosted?

Não. O app de desktop roda o runelay no seu computador em 127.0.0.1:4312. Servidor com Docker faz sentido quando você quer ele sempre ligado, para toda máquina que usa.

O runelay roda algum modelo?

Não. Quem pensa é o seu agente. O runelay é onde ele encontra tools, skills e memória.

Quais agentes podem usar?

Qualquer cliente MCP: Claude Code, Codex, Cursor, Grok, Antigravity e outros. Todos apontam para o mesmo endpoint /v1/mcp.

E se eu perder o RUNELAY_SECRET?

Ele criptografa conexões, tokens OAuth e chaves. Sem ele você reconecta tudo, então faça backup do ~/runelay/.env.
