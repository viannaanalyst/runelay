Download runelay

The whole server in one app for your computer. No Docker: open it, create your account and point your agents at it.

  • Mac Apple silicon and Intel Apple siliconIntel
  • Linux x64 and arm64 · AppImage x64arm64
  • Windows x64 · Windows 10 or newer Download
  • Server Docker, on any machine you keep on Install

Then

  1. 1

    Install it

    Mac: drag runelay from the .dmg into Applications. The first time, macOS blocks it: open System Settings › Privacy & Security and press Open Anyway. Windows: run the installer. Linux: run the .AppImage.

  2. 2

    Create your account

    Open the app. The first screen creates the owner account, no token to paste.

  3. 3

    Plug in your agents

    Install the CLI and bring everything you already have.

    $curl -fsSL runelay.com/cli | sh && runelay migrate

Want it on a server instead? Install with Docker
